\#{ resumeow — "sleek-rosepine": the sleek-dark two-column sidebar layout recoloured to the user's "Rosé Pine Ember" base24 scheme (~/.config/tinted-theming/rosepine.yaml). Warm rose-cream foreground on the authentic cool plum base; gold is the protagonist accent, iris carries the code chips. Unlike sleek-dark this does NOT derive its palette from the YAML `color` — Rosé Pine needs a full palette, so the slots are hardcoded and `color` is ignored. Same data + same render.py. }
